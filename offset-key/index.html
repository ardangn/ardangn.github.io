Offset Key

Experiment with timing across a rig without moving keys one by one.

  • Offset: Shift each control's keys earlier or later with its own slider. Return it to zero to restore the original timing, or commit the change.
  • Randomize: Generate fresh offsets within the minimum and maximum you set.
  • Stagger: Apply a starting offset and a step in list order. Reorder the list to change which controls move first.
  • Border keys: Optionally add keys at the first and last frames of your chosen range.
