Autodesk Maya animation tool

Offset Key

Experiment with timing across a rig. Shift animation earlier or later, spread movement across controls, and add variation without moving keys one by one.

Offset

Move each control's keys earlier or later with its own slider. Return the slider to zero to restore the original timing, or commit the new timing when you're happy with it.

Randomize

Set a minimum and maximum offset, then generate fresh timings for the controls in your list.

Stagger

Set a starting offset and a step to space the controls in list order. Reorder the list to change which parts move first.

Border keys

Optionally add keyframes at the first and last frames of your chosen range.
