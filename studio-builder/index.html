Claude Code game studio

Studio Builder

Set up a team of Claude Code agents inside a game project, then watch them work on the Studio Floor.

  • Director: Plans each request, briefs the right lead, and checks the result before calling it done.
  • Leads and workers: Design, mechanics, logic, UI, art, QA and release, each with its own skills, rules and docs.
  • Parallel work: Agents work at the same time, and none overwrites a file another agent is still working on.
  • QA first: Nothing counts as finished until QA has verified it.
  • Two profiles: PC games in Unity with PlayMaker, or mobile and web games.
  • Tool setup: Agents connect to Unity, Maya, Blender or Blockbench, and install FishNet for multiplayer.
  • Studio Floor: A live panel shows every agent at its desk, the model it runs on, and a feed of briefs and finished tasks.
